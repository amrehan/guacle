## Show HN
Title: Show HN: Guacle, a daily Fruit Ninja-style guac speedrun (and I trained an AI to set the record)
URL: https://amrehan.github.io/guacle/
First comment: It's one HTML file: canvas polygon slicing (Sutherland–Hodgman), a small rigid-body step, and sprite-cached pieces, so hundreds of fragments stay at 60fps. I ported the game to Node and trained a policy network plus beam-search planner under human swipe-speed limits. Its best run is 11.8s, and the estimated human floor is about 9.5s. About 57% of a perfect run is animation, so the trick is fewer, longer swipes, not more cuts.
